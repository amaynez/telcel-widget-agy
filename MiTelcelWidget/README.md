# MiTelcelWidget

## Overview
Native iOS 17+ WidgetKit extension and shared multi-carrier networking/parsing library (`TelcelNetworkService` and `MiTelcelWidgetCardContent`) supporting Mi Telcel, Mi Bait, Mi Movistar, and Mi AT&T with AppIntents configuration (`TelcelWidgetConfigIntent`), interactive refresh (`RefreshTelcelUsageIntent`), Keychain storage, and App Group caching. Part of the root technical blueprint ([`../README_TECH.md`](../README_TECH.md)).

## Invariants
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelUsageEntry.gbDivisor]` Uses `1000.0` for `carrier == "telcel"` and `1024.0` for all other carriers; `remainingGB` clamps `availableMB / gbDivisor` to `>= 0`; `usageRatio` returns `0` when `totalMB <= 0` and otherwise clamps `consumedMB / totalMB` to `[0.0, 1.0]`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelUsageEntry.isError]` Entry is treated as an error state when `date == .distantPast`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.normalizePhone]` Filters input to numeric digits and keeps the last 10 characters; `daysUntil` clamps calendar day difference between `startOfDay(for: now)` and `startOfDay(for: target)` to `>= 0`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.decryptMovistarContent]` Requires payload format `<base64url_cipher>:<base64url_iv>` where decoded `cipherData` is `>= 16` bytes (last 16 bytes used as AES-GCM tag) and `guardKey` is UTF-8 symmetric key.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.aesDecryptATT]` Requires Base64 input `>= 16` bytes prefixed with 8-byte ASCII `Salted__` followed by 8-byte salt, deriving key (32B) and IV (16B) via MD5 `evpBytesToKey` for AES-CBC PKCS7; `aesEncryptATT` checks `SecRandomCopyBytes` return status `== errSecSuccess` for 8-byte salt generation before encrypting.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.fetchUsage]` Only persists override credentials to Keychain/UserDefaults after the live network fetch for that carrier succeeds; requires 10-digit phone (and non-empty password for `.telcel`/`.att`, non-empty token for `.movistar`).
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.fetchTelcelUsage]` Authenticates via WebLogin 8443 with automatic fallback to OIDC (`https://www.mitelcel.com/oid-authorize-prod`) when `resolvedSSOToken` is nil or empty; resolves authorization redirect locations from headers or response URL; executes SSO token revocation (`revokeSSOToken`) in a `defer` block and awaits `revocationTask` completion before returning whenever `ssoToken` was acquired.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.parseHomeFlowJSON]` Prefers non-web `tabs-plans-v2-plan-name-` suffixes over `web-` suffixes, sorts suffixes numerically by hyphen-delimited components, defaults to `["0-0-0"]` if empty, identifies base buckets via `0-0-0` / `web-0-0-0`, filters zero-available promotional buckets ONLY when multiple promotional buckets exist and at least one has active data (`hasActivePromo`) to eliminate obsolete mid-cycle plan-change buckets while preserving legitimately exhausted promotions and 100% consumed plans, converts GB using `1 GB = 1000 MB` and KB using `1 MB = 1024 KB`, discards empty buckets (`bTotal <= 0 && bAvail <= 0`), defaults `daysLeft` to `28` if missing, and throws `URLError(.cannotParseResponse)` when `buckets.isEmpty`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.parseBaitJSON]` Requires `root["success"] == true` and `data` array; aggregates `BestEffort`, `Throttling`, and non-expired (`exp >= today`) `Benefits.offers_detail` buckets; marks `isUnlimited = true` when `category == "Data"`, `type` is not `SocialMedia`/`Unkown`, and `unlimited == true`; throws `URLError(.cannotParseResponse)` if `buckets.isEmpty`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.parseMovistarJSON]` Requires non-empty `bolton` array; skips items whose name starts with `redes sociales`, `minutos`, `sms`, `voz`, or `mensajes`; converts units with `1 TB = 1024*1024 MB`, `1 GB = 1024 MB`, `1 KB = 1/1024 MB`; clamps percentage-based consumption to `0...100`; throws `URLError(.cannotParseResponse)` if `buckets.isEmpty && !isUnlimited`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.parseATTJSON]` Requires non-empty `rawAllowances`; skips social/streaming/voice/SMS allowances, non-byte `UnitType` values, and expired (`endDt < today`) allowances; converts units using binary `1024` factors; treats `Unlimited == "Y"` or `total >= 99_999_000` MB as `isUnlimited = true`; throws `URLError(.cannotParseResponse)` if `buckets.isEmpty && !isUnlimited`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.loadCache]` Returns `nil` when `maxAge` is provided and `Date.now.timeIntervalSince(cached.date) > maxAge`; sets returned `isCached` to `maxAge == nil`.
- `[MiTelcelWidget/TelcelNetworkService.swift:MiTelcelWidgetCardContent]` Traffic-light color for `daysLeft`: `<= 2` red, `<= 5` yellow, `> 5` white; gauge arc applies a `0.03` gap when `0.04 < usageRatio < 0.96` and hides spent/available arcs when `totalMB <= 0`.

## Side Effects
- `[MiTelcelWidget/MiTelcelWidget.swift:RefreshTelcelUsageIntent.perform]` Calls `TelcelNetworkService.shared.fetchUsage(carrier:forceRefresh: true)` and reloads `WidgetCenter` timelines for kind `"MiTelcelUsageWidget"`.
- `[MiTelcelWidget/MiTelcelWidget.swift:MiTelcelTimelineProvider.timeline]` Calls `TelcelNetworkService.shared.fetchUsage(...)` and schedules next WidgetKit timeline reload 30 minutes in the future.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.setKeychain]` Reads/updates/adds/deletes `kSecClassGenericPassword` items in iOS Keychain under service `"mx.mitelcel.widget"` with `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`; `migrateKeychainAccessibilityIfNeeded` re-saves existing Keychain items once and sets `"keychain_accessibility_migrated_v2" = true` in `UserDefaults`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.saveCredentials]` Writes credentials to Keychain and non-secret phone numbers to `UserDefaults(suiteName: "group.mx.mitelcel.widget")`, while removing `"telcel_pass"`, `"att_pass"`, and `"movistar_pid"` from `UserDefaults`.
- `[MiTelcelWidget/TelcelNetworkService.swift:TelcelNetworkService.fetchUsage]` Creates an ephemeral `URLSession`, performs carrier network requests (`fetchTelcelUsage` via WebLogin or OIDC, `fetchBaitUsage`, `fetchMovistarUsage`, `fetchATTUsage`, `fetchDynamicMtlBasic`, `fetchMovistarGuardKey`), writes JSON usage cache via `saveCache` to the App Group container URL (or fallback `.documentDirectory`), or reads fallback cache via `loadCache`.
